# 🎬 MacMediaWatcher

[![en](https://img.shields.io/badge/lang-English-blue)](README.md) [![ru](https://img.shields.io/badge/lang-Русский-red)](README.ru.md)

Автоконвертер неподдерживаемых форматов для видеомонтажа на macOS.

Если монтируешь видео в **DaVinci Resolve**, **Premiere Pro**, **Final Cut Pro** или любом другом видеоредакторе, то знаешь эту боль: качаешь материал со стоков типа Envato, Freepik, Shutterstock или Adobe Stock, а там вместо нормальных файлов прилетает **AVIF**, **SVG**, **TIFF** или архив **.ZIP**, внутри которого ещё надо раскопать нужное видео. Редактор такое не жрёт, и каждый раз приходится руками конвертить, распаковывать, удалять мусор.

**MacMediaWatcher** решает эту проблему. Он висит в фоне и следит за рабочими папками. Как только появляется файл в неподдерживаемом формате — автоматически конвертит или распаковывает его, а оригинал удаляет. Ты просто качаешь со стока, а в папке уже лежит готовый к импорту файл.

## Что делает

### Конвертация изображений

Конвертация работает через **`sips`** (Scriptable Image Processing System) — утилиту, встроенную в macOS. Она идёт из коробки с любым маком, ничего ставить не нужно. `sips` умеет работать с кучей форматов и конвертить их в стандартные JPEG/PNG без потери качества.

| Формат | Результат | Команда |
|--------|-----------|---------|
| `.avif` | `.jpg` | `sips -s format jpeg` |
| `.tif` `.tiff` | `.jpg` | `sips -s format jpeg` |
| `.svg` | `.png` | `sips -s format png -Z 2000` (максимальная сторона — 2000px, настраивается) |

Оригинальный файл удаляется после успешной конвертации.

### Распаковка ZIP-архивов

Многие стоки отдают материалы в ZIP-архивах, где нужное видео лежит в глубине рядом с кучей мусора (превью, лицензии, README и т.д.). MacMediaWatcher:

1. Открывает ZIP-архив
2. Ищет внутри только видеофайлы нужных форматов (`.mp4`, `.mov`, `.mkv`, `.avi`, `.m4v`, `.webm`, `.prores`)
3. Извлекает их в ту же папку, где лежал архив
4. Игнорирует системный мусор (`__MACOSX`, `.DS_Store`)
5. Удаляет ZIP-архив

На выходе — чистые видеофайлы рядом с остальными материалами, без лишних папок и мусора.

## Требования

- **macOS** (конвертация через встроенную утилиту `sips`, не работает на Windows/Linux)
- Python 3.8+

## Установка

```bash
git clone https://github.com/raywari/MacMediaWatcher.git
cd MacMediaWatcher
pip3 install -r requirements.txt
```

## Настройка

При первом запуске автоматически создаётся `config.yaml` из шаблона `config.example.yaml`. Открой его и пропиши свои пути:

```yaml
watch_dirs:
  - ~/Desktop/Projects
  - /Volumes/SSD/Footage

ignored_dirs:
  - "TEMPLATES"
  - "ASSETS"

# Обрабатывать файлы только внутри подпапок с этим именем.
# Оставь пустым (""), чтобы обрабатывать всё подряд.
target_folder: "DOWNLOADS"
```

Полный список настроек (потоки, таймауты, форматы, ретраи) — смотри в [`config.example.yaml`](config.example.yaml).

## Запуск

```bash
python3 watcher.py
```

Для фонового запуска при старте системы можно использовать `launchd` (macOS) — создай `.plist` файл в `~/Library/LaunchAgents/`.

## Как это работает

1. При запуске сканирует все целевые директории и обрабатывает уже имеющиеся файлы
2. Запускает `watchdog` observer на каждую директорию
3. Новые файлы попадают в очередь → проверяется стабильность (ждёт, пока файл полностью скачается) → конвертация/распаковка
4. Распаковка и конвертация идут в отдельных потоках (до 4 параллельно, настраивается)
5. Если директория отключается (внешний диск), скрипт ждёт её появления и автоматически подключается обратно
6. Если обработка файла упала — до 3 автоматических повторов с нарастающим интервалом (30с, 90с)
7. При аварийном завершении скрипт при следующем запуске подчищает за собой временные файлы
